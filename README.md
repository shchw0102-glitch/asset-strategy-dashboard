# 모아 — 개인 자산 대시보드

현금·예금, 주식·ETF, 가상자산, 부동산, 기타 자산을 관리하는 한국어 개인 자산 관리 웹앱입니다.

## 제공 기능

- 총 평가금액, 매입 원금, 평가 손익과 단순 수익률
- 자산 구성 차트와 현재·목표 비중 비교
- 자산 추가·수정·삭제, 이름·메모 검색, 유형 필터
- 목표 비중 설정과 총자산 유지 기준의 조정 금액
- 브라우저 로컬 저장, JSON 백업 내보내기·가져오기
- 샘플 데이터와 빈 포트폴리오 전환, 모바일 화면 지원
- 업비트 원화 마켓 실시간 시세와 보유 수량 기반 코인 평가
- 네이버페이 자동 계좌 가져오기의 지원 범위와 수동 계좌 잔액 기록 안내

처음 실행할 때 **샘플** 자산을 표시합니다. `내 자산으로 시작`을 누르면 빈 목록에서 직접 기록할 수 있습니다. 자산은 동일한 브라우저와 사이트 주소에 저장되며 계정·서버 동기화는 없습니다. 브라우저 기록을 지우거나 기기를 옮기기 전에 `데이터 관리`에서 백업하세요.

## 업비트 시세와 금융계좌

대시보드 또는 `시세·계좌`에서 코인의 `자산 추가`를 누르거나, 자산 유형을 `가상자산`으로 선택하세요. 원금과 보유 수량을 입력하면 업비트 원화 시세 × 수량으로 평가금액, 손익과 자산 배분을 계산합니다. 수량은 직접 입력하며 **업비트 계좌 잔고·거래 권한은 연결하지 않습니다**. API 키가 필요하지 않고 시세 구독에는 마켓 코드만 전송합니다.

시세는 업비트 공개 WebSocket에서 수신하고 화면은 1초 단위로 갱신합니다. 기본 BTC·ETH·XRP와 등록·편집 중인 코인을 함께 구독합니다. 재연결은 15초부터 최대 60초까지 간격을 늘리며, 구독 변경도 10.5초 이상 간격을 두어 Origin 요청 제한을 존중합니다. 마지막 수신 후 60초 이상 지난 시세나 끊긴 연결은 실시간으로 표시하지 않습니다. 연결 장애 시에는 캐시 시세 또는 마지막 저장 평가금액을 유지하며 상태를 표시합니다. 시세 캐시는 15초마다 저장하고, 백업에는 현재 평가금액과 연동 마켓·수량을 함께 담습니다. 기존 4개 자산 유형의 기록·목표 비중·백업은 그대로 읽고, 가상자산 목표 비중은 0%로 추가합니다.

**네이버페이 개인 금융계좌 자동 가져오기는 구현하지 않았습니다.** 확인한 공개 개발자 문서는 결제·주문·정산 연동용이며 개인 계좌와 잔액을 가져오는 공개 API는 확인되지 않았습니다. 네이버 로그인이나 네이버페이 결제 API를 자산 조회 API로 사용하지 않습니다. 앱의 `시세·계좌`에서 네이버페이를 열어 잔액을 확인한 후 계좌별명과 잔액을 수동 기록할 수 있습니다. 네이버페이에서 CSV를 내려받을 수 있다고 가정하지 않습니다.

금융계좌 자동 연결을 추가하려면 승인된 마이데이터 또는 오픈뱅킹 제공자의 계약·API 접근, 이용자 본인 인증·정보 제공 동의, 토큰을 보관하고 갱신할 서버가 별도로 필요합니다. 공개 GitHub Pages나 브라우저 저장소에 금융 API 비밀 키를 넣지 마세요. 승인된 네이버페이 파트너 API가 있다면 해당 계약의 지원 범위를 별도로 확인해야 합니다.

## 실행

Node.js 22.12 이상이 필요합니다. 클라우드 환경에서는 Node.js 24로 검증했습니다. 별도 데이터베이스, 환경 변수, API 키는 필요하지 않습니다.

```bash
cd /workspace/asset-strategy-dashboard
npm ci --cache /workspace/.npm-cache
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

로컬 컴퓨터에서는 프로젝트 폴더에서 `npm ci`와 `npm run dev`를 실행하면 됩니다.

## 검증과 빌드

```bash
npm test
npm run build
npm run preview -- --host 0.0.0.0 --port 4173 --strictPort
```

빌드는 TypeScript 검사 후 `dist/`에 정적 웹앱을 생성합니다. `preview`는 빌드 결과 확인용입니다. 개발 서버 주소와 배포 주소는 서로 다른 저장 공간을 사용합니다.

공개 사이트: https://shchw0102-glitch.github.io/asset-strategy-dashboard/

GitHub Pages 갱신은 `npm run build:pages`로 자바스크립트·CSS를 포함하는 단일 `docs/index.html`을 만든 뒤, 소스와 생성된 `docs/`를 함께 `main`에 저장합니다. GitHub Pages 소스는 `main`의 `/docs`입니다. 일반 `npm run build`는 추적된 Pages 파일을 바꾸지 않아 온보딩 검증에도 사용할 수 있습니다. 단일 HTML도 실시간 시세에는 인터넷 연결이 필요합니다.

## 계산 기준

- 평가 손익 = 현재 평가금액 − 매입 원금
- 평가 수익률 = 평가 손익 ÷ 매입 원금 × 100. 원금이 0이면 계산하지 않습니다.
- 비중은 현재 평가금액 기준입니다. 부채·세금·거래 수수료는 계산에 포함하지 않습니다.
- 목표 비중은 각 0~100%, 전체 합계 100%여야 합니다.
- 조정 금액은 현재 총자산을 유지하면서 목표 배분으로 바꿀 때의 차이이며 원 단위로 반올림합니다. 자산별 반올림으로 합계에 소액 차이가 생길 수 있습니다.
- 원화 정수만 입력합니다. 외화 자산은 원화로 환산해 입력하세요.
- 코인 보유 수량은 소수를 허용하고 평가금액은 원 단위로 반올림합니다. 1원 미만 코인 시세는 소수점을 보존해 표시합니다.

## 프로젝트 구성

`src/App.tsx`에 화면과 저장·백업 기능, `src/portfolio.ts`에 자산 계산과 입력 검증, `src/portfolio.test.ts`에 계산·백업 검증 테스트가 있습니다. `src/styles.css`에서 반응형 디자인을 관리합니다. React, TypeScript, Vite와 Vitest를 사용합니다.

클라우드 작업은 이미 격리되어 있으므로 기존 체크아웃을 사용하세요. 사용자가 명시적으로 요청하지 않는 한 별도 Git worktree를 만들 필요가 없습니다.
