# 모아 — 개인 자산 대시보드

현금·예금, 주식·ETF, 부동산, 기타 자산을 직접 기록하는 한국어 개인 자산 관리 웹앱입니다.

## 제공 기능

- 총 평가금액, 매입 원금, 평가 손익과 단순 수익률
- 자산 구성 차트와 현재·목표 비중 비교
- 자산 추가·수정·삭제, 이름·메모 검색, 유형 필터
- 목표 비중 설정과 총자산 유지 기준의 조정 금액
- 브라우저 로컬 저장, JSON 백업 내보내기·가져오기
- 샘플 데이터와 빈 포트폴리오 전환, 모바일 화면 지원

처음 실행할 때 **샘플** 자산을 표시합니다. `내 자산으로 시작`을 누르면 빈 목록에서 직접 기록할 수 있습니다. 자산은 동일한 브라우저와 사이트 주소에 저장되며 계정·서버 동기화는 없습니다. 브라우저 기록을 지우거나 기기를 옮기기 전에 `데이터 관리`에서 백업하세요. 실시간 시세나 금융 계좌 연결은 제공하지 않습니다.

## 실행

Node.js 22.12 이상이 필요합니다. 클라우드 환경에서는 Node.js 24로 검증했습니다. 별도 데이터베이스, 환경 변수, API 키는 필요하지 않습니다.

```bash
cd /workspace/asset-strategy-dashboard
npm ci --cache /workspace/.npm-cache
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

로컬 컴퓨터에서는 프로젝트 폴더에서 `npm ci`와 `npm run dev`를 실행하면 됩니다.

## 검증과 빌드

```bash
npm test
npm run build
npm run preview -- --host 0.0.0.0 --port 4173 --strictPort
```

빌드는 TypeScript 검사 후 `dist/`에 정적 웹앱을 생성합니다. `preview`는 빌드 결과 확인용입니다. 웹사이트를 공개하려면 `dist/`를 정적 호스팅에 배포해야 합니다. 개발 서버 주소와 배포 주소는 서로 다른 저장 공간을 사용합니다.

## 계산 기준

- 평가 손익 = 현재 평가금액 − 매입 원금
- 평가 수익률 = 평가 손익 ÷ 매입 원금 × 100. 원금이 0이면 계산하지 않습니다.
- 비중은 현재 평가금액 기준입니다. 부채·세금·거래 수수료는 계산에 포함하지 않습니다.
- 목표 비중은 각 0~100%, 전체 합계 100%여야 합니다.
- 조정 금액은 현재 총자산을 유지하면서 목표 배분으로 바꿀 때의 차이이며 원 단위로 반올림합니다. 자산별 반올림으로 합계에 소액 차이가 생길 수 있습니다.
- 원화 정수만 입력합니다. 외화 자산은 원화로 환산해 입력하세요.

## 프로젝트 구성

`src/App.tsx`에 화면과 저장·백업 기능, `src/portfolio.ts`에 자산 계산과 입력 검증, `src/portfolio.test.ts`에 계산·백업 검증 테스트가 있습니다. `src/styles.css`에서 반응형 디자인을 관리합니다. React, TypeScript, Vite와 Vitest를 사용합니다.

클라우드 작업은 이미 격리되어 있으므로 기존 체크아웃을 사용하세요. 사용자가 명시적으로 요청하지 않는 한 별도 Git worktree를 만들 필요가 없습니다.
